# La Mesa Secreta

Aplicación de Next.js creada a partir del mockup exportado en `Main.dc.html`.

## Comandos

```bash
npm install
npm run dev
```

La app queda disponible en `http://localhost:3000`.

## Estructura

- `app/page.tsx`: página principal y contenido editable.
- `app/ReservationForm.tsx`: formulario cliente que arma el mensaje de WhatsApp.
- `app/globals.css`: estilos responsivos basados en el diseño.
- `public/images/`: fotos servidas desde Next.
- `Main.dc.html` y `assets/`: referencia original del diseño.
